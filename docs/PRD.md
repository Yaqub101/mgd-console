1. Product Name

MGD Console
Trainer Analytics Dashboard

2. Product Overview

MGD Console is a lightweight analytics dashboard designed for fitness trainers to analyze client data using structured CSV input.

The system transforms raw client data into meaningful visual insights to assist in data-driven decision-making.

3. Target Users

Independent personal trainers

Gym coaches

Small fitness studio owners

4. Problem Statement

Trainers manage client information in spreadsheets but lack tools to:

Analyze client demographics

Evaluate health metrics

Understand goal distribution

Identify risk patterns

Manual spreadsheet analysis is time-consuming and inefficient.

5. Objective

To develop a web-based descriptive analytics system that:

Accepts structured CSV input

Performs data cleaning

Calculates derived health metrics

Visualizes client statistics

Generates rule-based insights

6. Scope
In Scope

CSV upload

Data processing

BMI calculation

Dashboard metrics

Data visualization

Client detail view

Rule-based insights

Out of Scope

Database integration

User authentication

Machine learning models

Predictive analytics

Multi-user system

7. Success Criteria

The system is successful if:

CSV is correctly processed

Dashboard displays accurate metrics

Charts reflect computed statistics

Client detail view works correctly

Insights follow defined logical rules
